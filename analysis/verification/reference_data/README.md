# Reference Data for Hydrogen Tank Modelling

This directory contains reference data extracted from literature for validation and comparison with simulation results.

## Data Sources

The data in these CSV files is extracted from the following publications:

1. DOI: [10.1016/j.cryogenics.2024.103826](https://doi.org/10.1016/j.cryogenics.2024.103826)
2. DOI: [10.1016/j.cryogenics.2023.103743](https://doi.org/10.1016/j.cryogenics.2023.103743)

## File Descriptions

- `discharge_data.csv`: Reference discharge path in temperature-density space
- `refuel_data.csv`: Reference refueling path in temperature-density space
- `dormancy_data.csv`: Reference dormancy path in temperature-density space

## Data Format

Each CSV file contains two columns:
1. Temperature (K)
2. Density (g/L)

No headers are included in the CSV files.
