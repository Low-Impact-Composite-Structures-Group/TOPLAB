 # Verification Reference Data (Stops et al., 2024)

 This directory contains reference data originating from the study by Stops et al. published in Cryogenics (2024). It is provided here solely to serve as a benchmark for validating the multi-tank analysis tool in this repository.

 - Paper DOI: https://doi.org/10.1016/j.cryogenics.2024.103826
 - Purpose: Use these data to sanity-check that the multi-tank simulations reproduce the expected physical behaviour and key trends reported in the paper.
